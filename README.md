# Личное дело — сайт-визитка

Статичный сайт (HTML/CSS/JS, без сборки и зависимостей) в стиле служебного досье:
персона-переключатель Andrey Oreo / Frank Zetix, послужной список по городам
(Москва → Ялта → Севастополь) и каналы связи.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub, например `my-profile`.
2. Загрузи в него файлы `index.html`, `style.css`, `script.js`, а также папку
   `assets` целиком (в ней лежит эмблема — `emblem-hero.png`, `emblem-256.png`, `favicon.png`)
   (через "Add file → Upload files" — папку можно перетащить целиком, GitHub сохранит
   структуру, либо через git — см. ниже).
3. Зайди в репозитории в **Settings → Pages**.
4. В разделе "Build and deployment" выбери **Source: Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Нажми **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<твой-логин>.github.io/<имя-репозитория>/`

## Как выложить через git (если предпочитаешь терминал)

```bash
git init
git add index.html style.css script.js assets
git commit -m "Личное дело: первая версия сайта"
git branch -M main
git remote add origin https://github.com/<твой-логин>/<имя-репозитория>.git
git push -u origin main
```

## Структура файлов

- `index.html` — разметка страницы (шапка, hero, блок «Обо мне» с переключателем
  личных дел, послужной список, контакты)
- `style.css` — все стили и токены дизайна (цвета, шрифты, анимации)
- `script.js` — данные по обоим позывным и логика переключения/анимаций
- `assets/` — эмблема (используется как значок вкладки, в hero и на ID-карточке)

## Что можно поправить самостоятельно

- Данные персон и послужного списка — в начале `script.js`, в объекте `personas`.
- Ссылки на контакты — в `index.html`, секция `<section class="contacts">`.
- Цвета — в `style.css`, блок `:root { ... }` в самом верху файла.
